# AnimeAvatar - публичные установщики

[Скачать последнюю версию](https://github.com/maxwell2010/AnimeAvatar-releases/releases/latest)

Экспериментальный Windows x64 виджет с 3D-аватаром, прозрачным окном, локальным импортом VRM, анимациями и диалогом через Ollama или OpenAI.

- `AnimeAvatar-Setup-<версия>-x64.exe` - личная некоммерческая версия с персонажами LivLiv. Их лицензия и атрибуция входят в приложение. Персонажи не предназначены для перепродажи.
- `AnimeAvatar-Originals-Setup-<версия>-x64.exe` - версия без сторонних персонажей, для импорта собственных VRM. Использует отдельный профиль настроек.
- `SHA256SUMS.txt` - SHA-256 установщиков. Проверка в PowerShell: `Get-FileHash .\AnimeAvatar-Setup-0.4.9-x64.exe -Algorithm SHA256`.

Установка для текущего пользователя. Установщики пока без сертификата подписи проекта. Анимации и физика ткани экспериментальные.

Личные модели, Мята, история диалогов, API-ключи, настройки и веса ИИ в установщики не входят. Для локального ИИ есть настройка Ollama в приложении; для OpenAI нужен собственный ключ. Интернет используется при обращении к выбранному провайдеру и источникам справки согласно настройкам.

Этот репозиторий содержит только публичные материалы релизов. Репозиторий разработки закрыт. Ошибки можно сообщать через Issues, не публикуя ключи, личные беседы и другие секреты.
