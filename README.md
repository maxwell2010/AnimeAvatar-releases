# AnimeAvatar - ИИ-компаньон для Windows

[Скачать последнюю версию](https://github.com/maxwell2010/AnimeAvatar-releases/releases/latest)

Экспериментальный Windows x64 виджет: прозрачный фон, перетаскивание, выбор
персонажа и размера, диалог в полупрозрачном окне, характер и реакции мимикой
и анимациями. Поддерживаются локальный Ollama и OpenAI со своим API-ключом.

## Какой установщик выбрать

- **AnimeAvatar-Setup-<версия>-x64.exe** - полная версия. В 0.4.12 входят
  **166 персонажей**: 115 Microsoft Rocketbox, 45 выбранных CC0, Мята и 5 LivLiv.
  Аватары уже включены, дополнительное скачивание не требуется.
- **AnimeAvatar-Originals-Setup-<версия>-x64.exe** - отдельная поставка без
  сторонних персонажей, для импорта собственных VRM. Использует отдельный профиль.
- **SHA256SUMS.txt** - контрольные суммы установщиков. Проверка в PowerShell:
    `Get-FileHash .\AnimeAvatar-Setup-0.4.12-x64.exe -Algorithm SHA256`

## Подключение ИИ

При первом запуске без настроенного ИИ приложение предлагает проверить компьютер
и подобрать локальную модель. Для загрузки Ollama и весов нажмите
«Установить и подключить». Можно выбрать «Позже» и вернуться к установке
в настройках диалога. Веса ИИ в установщик не входят и без нажатия кнопки
не скачиваются. Для OpenAI нужен собственный API-ключ.

Личные модели BOOTH с запретом или неподтверждённым правом распространения,
история диалогов, API-ключи и настройки пользователей в установщики не входят.
Доступны локальный импорт VRM/VRMA и ссылки на авторов сторонних моделей.
